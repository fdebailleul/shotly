# Captur Ecran - Installation

## Installation dans Chrome

1. Ouvrez Chrome et allez dans `chrome://extensions/`
2. Activez le **Mode développeur** (interrupteur en haut a droite)
3. Cliquez sur **Charger l'extension non empaquetee**
4. Selectionnez le dossier `captur-ecran-extension`
5. L'extension apparait dans la barre d'outils

## Raccourcis clavier

| Raccourci | Action |
|-----------|--------|
| `Alt+Shift+V` | Capturer la zone visible |
| `Alt+Shift+F` | Capturer la page entiere |
| `Alt+Shift+A` | Capturer une zone selectionnee |

## Raccourcis editeur

| Touche | Outil |
|--------|-------|
| `V` | Selection |
| `R` | Rectangle |
| `C` | Cercle |
| `A` | Fleche |
| `L` | Ligne |
| `F` | Dessin libre |
| `T` | Texte |
| `B` | Flou |
| `H` | Surbrillance |
| `X` | Recadrage |
| `Ctrl+Z` | Annuler |
| `Ctrl+Y` | Retablir |
| `Suppr` | Supprimer l'annotation selectionnee |

## Fonctionnalites

- Capture de la zone visible, page entiere, zone selectionnee, ecran/fenetre
- Capture differee (3s, 5s, 10s)
- Editeur d'annotations complet (formes, fleches, texte, flou, surbrillance)
- Recadrage interactif
- Export PNG, JPG, PDF
- Copie dans le presse-papiers
- Ouverture d'images locales / collage depuis le presse-papiers
- Interface bilingue FR/EN (detection automatique)
